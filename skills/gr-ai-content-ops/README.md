# AI Content Operations / AI 内容运营

An installable agent skill for source libraries, channel roles, weekly content planning, editorial gates, repurposing, distribution receipts and measurable reviews.

## Install

```bash
npx skills add Gingiris-1031/gingiris-skills --skill gr-ai-content-ops
```

## Use

“我们每周有 8 小时，有两份产品演示和三篇访谈。请做一周内容排期，标出待核证据、负责人和交付回执。”

“Use our content history to diagnose the bottleneck and plan one measurable experiment. Do not publish.”

Outputs include a channel/capacity card, source register, weekly calendar, parent/variant map, delivery ledger and review memo as needed. Supports Chinese or English output. No API key or companion skill is required for planning from supplied material; live analytics and publishing need the relevant platform access and authorization.

This skill coordinates an operation. A single article adaptation belongs in a focused writing workflow. Publishing and direct messages require explicit authorization; unavailable metrics remain unknown.
