# AI Content Operations / AI 内容运营

An installable agent skill for audience-first content, competitor research, SEO/GEO positioning, substantive drafts and measurable content operations. 面向受众价值，连接竞品研究、关键词定位、完整内容与运营复盘。

## Install

```bash
npx skills add Gingiris-1031/gingiris-skills --skill gr-ai-content-ops
```

## Use

“我们每周有 8 小时，有两份产品演示和三篇访谈。请做一周内容排期，标出待核证据、负责人和交付回执。”

“Use our content history to diagnose the bottleneck and plan one measurable experiment. Do not publish.”

Outputs include a channel/capacity card, source register, weekly calendar, parent/variant map, delivery ledger and review memo as needed. Supports Chinese or English output. No API key or companion skill is required for planning from supplied material; live analytics and publishing need the relevant platform access and authorization.

This skill coordinates an operation. A single article adaptation belongs in a focused writing workflow. Publishing and direct messages require explicit authorization; unavailable metrics remain unknown.

## Version 1.1.0

Adds stage-matched competitor content research, dated launch evidence, transferability checks and evidence-to-experiment planning. 新增竞品早期内容研究、历史证据与可迁移性判断，调研结论直接连接内容实验。

The planning workflow now asks a short adaptive intake for product and competitor URLs, audience and desired action, skipping known answers and supporting products without public websites. 规划前主动补问产品/竞品网址、受众与目标；已有信息不重复询问，未上线产品可提供简述。

## Version 1.2.0

Adds website-to-social planning, existing-content claim audits, informative visual briefs, independent asset readiness and activation measurement. Includes dated public-source Ring2 and Analook planning examples, not performance case studies. 新增官网到社媒的内容流程，以 Ring2 和 Analook 展示不同的素材、证据和转化路径；案例不是增长成效背书。

### 1.2.1
Complete LinkedIn case/analysis drafts with substantive reasoning; cooperative claim-level verification of user-confirmed material. 完整长稿与逐项辅助验证，避免把核验缺口误写成内容不实。

## Version 1.3.0

Adds a pre-draft SEO/GEO brief: intent clusters, localized SERP evidence, page ownership, differentiated content positioning, evidence-backed outlines and separate citation/conversion measurement. 博客动笔前明确关键词、搜索意图、内容定位、URL分工与差异化证据；候选词不冒充已验证机会。

## Version 1.4.0

Audience value precedes keyword and production planning: recognisable situations, competing angles, substantive examples and reader-centred editing. 先判断潜在受众为什么愿意看，再做关键词、格式和分发；编辑评分不冒充受众验证。

## Version 1.5.0

Adds retrieval-first diagnosis, competing explanations, experiment feasibility, persistent state and bilingual field definitions; preserves audience-first writing and SEO/GEO positioning. 新增取数优先、原因判别、实验可判定性、跨会话台账与缺失恢复，按任务选择模板。
