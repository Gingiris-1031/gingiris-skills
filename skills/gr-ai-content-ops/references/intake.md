# Missing inputs and recovery / 输入缺失与恢复

Use the short intake in SKILL.md; these are execution checks, not a mandatory opening questionnaire.

| Gap | Useful next action | Delivery implication |
|---|---|---|
| Analytics exist but were not supplied | Retrieve accessible exports or assign a specific field request | Diagnosis provisional; independent drafting can continue |
| No account history | Establish baseline collection | No invented best/worst post |
| Footage lacks timecodes, redaction or revision | Schedule tagging/redaction/version selection as a production task | Storyboard can be complete; video remains pending |
| Consent scope is unclear | Confirm the specific use, audience and material; record evidence | Hold affected story; use other authorized material |
| Oral permission reported | Assess explicit scope and reliable record; seek clarification if insufficient | Do not presume either authorization or prohibition solely from medium |
| Names missing | Assign a role placeholder and assignment deadline | Plan can be delivered with visible handoff task |
| Quote cannot be checked against audio | Inspect another reliable original; omit disputed words or use supported attributed paraphrase | Paraphrasing does not make an unsupported claim true |
| Platform access unavailable | Use reliable current documentation for planning, label editor untested | No claim of account audit/publication |

For receipts, define the operator, due time, location and user-facing summary. Agree on realistic timing: acceptance/readback during the authorized session when possible, metrics at the chosen window (for example 24h and 7d). If delayed or blocked, record attempted time and next step. A schedule only exists when configured, not when written in a plan. Draft-only requests receive a receipt template labeled not executed.
