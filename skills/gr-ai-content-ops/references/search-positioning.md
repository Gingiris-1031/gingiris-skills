# SEO/GEO keyword and content positioning brief

## 1. Define the reader and decision

State audience, market, language, product stage and intended business action. Ask for missing context only if it changes the plan. Write a positioning sentence: “For [reader] facing [decision], this page explains [answer] using [specific evidence], so they can [next step].” This is the content's promise, not the company's slogan or a ranking forecast.

## 2. Research queries and answer needs

Start with accessible Search Console queries/pages and customer questions; record the date range, geography, branded/non-branded split and missing coverage. Add competitor pages, search suggestions and current localized search results as discovery sources. Inspect a small representative set of actual results for the dominant page type, audience, intent, useful depth and unanswered questions. Record query, locale, check date and URLs; a snippet or search suggestion alone is not demand measurement.

Use available keyword tools for volume, difficulty and related queries, retaining provider, geography, period and retrieval date. Numbers from different providers are not directly comparable. Avoid universal volume/KD thresholds or guaranteed ranking claims. Low-volume, high-relevance questions can still merit a page. If tools are unavailable, explicitly mark candidate keywords and metric gaps, continue provisionally and do not call them validated opportunities.

Select one coherent primary intent cluster, a small useful set of secondary phrases/entities and natural-language buyer questions. Distinguish product competitors from search competitors. Do not stuff all phrase variants into headings or impose keyword density. Prioritize buyer relevance, actual opportunity evidence, differentiated proof, product fit and production cost; high volume alone does not set priority.

## 3. Assign page ownership and a differentiated position

Inventory existing pages before selecting create/update/consolidate/defer. Map equivalent intent to a preferred existing URL where sensible. Repeated words do not automatically mean cannibalization; inspect whether pages answer the same decision and, when available, whether query/page data suggests competition. Redirects or consolidation are proposed changes requiring normal implementation scope, not automatic actions.

Choose a guide for an explanatory task, a product/solution page for a capability or purchase task, and a comparison page for an actual evaluation. Do not force transactional searches into blog posts. Multi-brand work needs domain-level topic ownership, too.

Specify what this page contributes beyond current results: a verified workflow, original evidence, an explicit tradeoff, a worked example or a reusable decision tool. Generic completeness is not a differentiated position. Comparisons require dated, fairly scoped evidence for each product; 'best' and competitor names are not mandatory title ingredients.

## 4. Build the article and citation-ready evidence

Draft a clear title, H1, opening answer, section outline, proposed meta description and stable URL. Use the primary language naturally. Map each section to a reader question and the evidence needed. Include a useful visual and relevant internal links toward deeper explanation and a product next step. Preserve date, methodology and limitations beside original figures; distinguish first-party experience from independent findings.

For AI-answer discovery, describe entities consistently and provide concise, self-contained explanations, supported comparison tables or examples where useful. Natural-language questions help scope coverage; do not generate repetitive FAQ pages. Clear formatting and valid structured data do not guarantee inclusion or citation. Check current official guidance before asserting engine-specific requirements; there is no universal GEO file/schema requirement.

For an AI visibility check, record engine/model if available, exact prompt, date, locale/account context, answer evidence and cited URL. Separate brand mention, linked citation, factual accuracy and referral/conversion. An unchecked prompt list is a test plan, not a visibility result.

## 5. Hand off to social and measurement

Create native social arguments from the page's specific decision or finding, not from the keyword list. Specify visual, destination and tracking. Assess search impressions/clicks by query/page, relevant AI citations and meaningful business events separately. Record a baseline and review window; unavailable metrics remain unknown. Publishing, technical eligibility, indexing, ranking, citation and conversion each require their own evidence.
