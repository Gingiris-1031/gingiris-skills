# Attribution model

Score each event from 0–8:

- +2 original content or first-party API evidence
- +2 publication within 48 hours before a star-velocity increase
- +1 meaningful observed public engagement
- +1 audience closely matches repository users
- +1 independent corroborating source
- +1 direct or reply-level repository link

Interpret 6–8 as high-confidence contributor, 3–5 as plausible amplifier, 1–2 as weak evidence, and 0 as unattributed.

Estimate ranges only after scoring all events in a stage. Model the system: seed channels create velocity, Trending amplifies it, KOL/media extend it, and tutorials/SEO capture delayed intent. Do not force overlapping ranges to sum to 100.

Stage rules:

- Preparation: conversion assets change before promotion.
- Community seed: first relevant discussions and early stars.
- Accumulation: steady growth without a dominant spike.
- Breakout: velocity exceeds the previous baseline by at least 3×.
- Localization/SEO: tutorials, comparisons, and non-English content dominate.
- Ecosystem: forks, contributors, integrations, and releases lead.
