# 来源与改编边界

此 Skill 由 Iris / Gingiris 的《公众号运营 SOP — 写作流程文档》（2026-10-19）及同包审稿清单、排版说明、WORKFLOW-BUGS 整理为通用工作流。经作者要求制作与发布。

保留：真实素材到选题、来源标注、内容审/终审分离、inline-CSS 排版、封面检查、草稿箱交付、人工定稿和故障复盘。

参数化：作者文风、系列名称、品牌颜色、封面模板、CTA、发布角色和节奏。原账号的生活场景示例不能当真实素材，个人风格不作为所有用户标准。

修正：不硬凑数字或标点配额；不默认说话人编号对应作者；不把普通 JSON 转义直接等同乱码；不依赖平台删除内部注释；不同来源的重复转载不构成独立验证。

未分发：原始私人逐字稿、客户资料、文章草稿、账号标识、个人联系信息、固定价目、旧发布/群发脚本及存在缺失外部依赖的原排版代码。附带本地交付工具为本 Skill 新写，无网络请求和凭证读取。平台后台能力与权限在执行时核验，不声称已完成任何账号的真实发布测试。
