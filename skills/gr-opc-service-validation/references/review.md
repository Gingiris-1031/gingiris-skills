Capacity = available work time minus existing commitments, administration, review and rest constraints. Divide only genuinely comparable remaining hours by observed service effort; report a range, not a guaranteed client count. Keep a buffer for variability. Delegation transfers work, not accountability; define admin, content review and professional judgment separately.

容量从可用工时减去已有交付、行政、审核与休息约束计算。仅用可比较的剩余工时与实际服务耗时估算范围，预留波动。行政、内容审核和专业判断分别分工；外包不自动转移最终责任。

Continue if evidence supports buyer value and sustainable delivery; change if demand exists but scope/price/ownership is wrong; pause if essential access, consent or economic fit is missing. Small samples remain provisional. Track the next comparable cycle rather than declaring a universal formula.

有客户价值与可持续交付证据可继续；需求存在但范围/价格/责任错配就修改；关键输入或经济适配缺失可暂停。小样本结论暂定，用下一轮相似任务验证。
