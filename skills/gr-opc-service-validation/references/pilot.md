## Synthetic example / 教学样例，不是真实业绩

A solo operator tests a landing-page diagnostic for one small software team. Deliverable: annotated review of one agreed page and a prioritized list of three changes. Excludes implementation and any conversion guarantee. Client supplies target users and page analytics if available. Acceptance checks the agreed page, evidence for each recommendation and ownership of next actions. The operator chooses an affordable time cap, quotes the scope, and records actual time and payment. If access or ownership is missing, narrow the test before starting; if changes expand beyond the page, renegotiate scope.

一个人测试“软件团队单页诊断”服务：交付一页批注与三项优先修改，不含开发和转化率保证。客户提供目标用户与可得数据；验收看页面范围、建议证据与下一步负责人。执行者自行设定可承担工时上限、报价并记录实际投入与付款。缺数据或责任人先缩范围，新增页面另谈范围。以上数字是示例，不是行业标准。

## Conversation prompts / 可直接使用的问题

- What happened the last time this task failed? / 上次这件事没做好，发生了什么？
- Who owns execution after my delivery? / 我交付后谁负责执行？
- What observable result makes this acceptable? / 什么可观察结果算验收通过？
- Which part would you pay for now, and what remains uncertain? / 哪部分现在愿意付费，什么还不确定？

Do not send these prompts externally without the user's instruction. / 未获外发授权，不自动联系客户。
