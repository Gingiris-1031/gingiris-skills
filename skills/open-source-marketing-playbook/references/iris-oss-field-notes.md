# Open-source global operations field notes

Synthesized from Iris's 22-slide open-source overseas-operations deck and supplied global-growth course.

## AFFiNE reference case

- About 6,000 stars in the first week; roughly 30,000 at the time of the deck.
- 29 GitHub Trending daily/weekly/monthly appearances were reported.
- Treat these as historical context, not a promised benchmark.

## Asset QA table

| Asset | Pass condition | Metric |
|---|---|---|
| Positioning | comparator + audience + user benefit is clear in one sentence | comprehension test |
| README | first value and quick start visible without hunting | repo→install |
| PR article | comparative advantage and proof can be excerpted | qualified referral traffic |
| Docs | stranger reaches first success | time-to-first-value |
| Community | channel owner, response SLA and next action defined | activated→retained |

## Contributor routing

Not every contributor is ready to code. Offer translation, docs, examples, issue triage, events, community and global-ops tracks with a named first task.

## Anti-vanity rule

Stars and Trending are acquisition signals. Continue only when the cohort produces activation, retained use, contributor activity or qualified commercial demand.
