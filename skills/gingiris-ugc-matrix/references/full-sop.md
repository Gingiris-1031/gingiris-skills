# UGC 创作者协作 SOP

本手册是可填写的操作流程，未提供可复现的客户增长保证。先读 [目标与素材实验](outcome-and-variants.md) 决定目标和激励。

## 1. 目标卡与招募

`产品/任务｜受众/地区｜主要结果｜自然分发或付费投放｜基线/未知项｜现金上限｜人工上限｜负责人｜复盘日`

从真实相关创作者、小规模公开招募或已同意联系的网络开始，按用户授权处理对外消息。筛选样例是否准确展示任务、与目标人群相关、原创且可授权。探索型创作者负责提出可测试概念；执行型创作者可采用已获授权格式。先做一小批，不用粉丝量或固定人数证明适配。

招募草稿：我们为[人群]解决[任务]，希望合作制作[产物]，计划在[平台/期限]使用。预算与报酬为[待约定]，包含[修改次数]，[是否广告复用]。你可以按自己的方式演示；合作关系会披露，不要求正面评价。请先分享相关作品与档期。

## 2. 可直接填写的 Brief

| 字段 | 填写要求 |
|---|---|
| 受众与任务 | 谁在什么时刻遇到什么问题 |
| 产品事实 | 已验证能力、版本、限制；未知功能不得宣称 |
| 创意假设 | 为什么此角度可能带来目标结果 |
| 结构 | 问题→真实演示→可验证结果→准确CTA；允许原创表达 |
| 必须展示 | 关键步骤、前置条件、产品名和真实结果 |
| 不得出现 | 假见证、未获授权肖像/素材、收益保证 |
| 交付 | 格式、比例、长度范围、字幕、源文件约定、截止时间 |
| 修改 | 包含轮次、验收人、超范围改动处理 |
| 权利 | 发布平台、使用期限、地区、广告复用、剪辑/翻译许可 |
| 披露 | 品牌合作、赞助、平台要求的AI标注 |
| 测量 | 素材ID、UTM/代码、落地页、事件定义、观察窗口 |

## 3. 成片验收与发布

逐项核对：事实准确；真实任务可复现；声音/字幕可理解；承诺与落地页一致；链接及事件正常；权利和披露齐全；修改闭环。未通过则具体指出需改的时间点和验收条件。

状态分为：已交稿→已验收→已授权发布→已发布/投放→已复盘→已结算。通过制作验收不等于达到成交目标，未成交也不自动取消合格制作费。发布、投流和支付需有对应授权；本SOP不构成外发许可。

## 4. 选择报酬与结算口径

- 传播：制作费，可加有效触达奖励；先约定有效播放、窗口和重复排除。
- 激活：制作费，可加首次价值事件奖励；明确用户去重和事件。
- 付费：制作费，可加归因净成交奖励；明确支付、退款、冲突归因、上限和结算日。

所有金额由范围、创意工作、使用权与预算协商，不能把示例当市场报价。相同素材在多平台或广告复用的权利与费用需明确约定。不给创作者不可控制或无法测量的收入保证责任；不以好评作为报酬条件。

## 5. 素材实验与追踪台账

`素材ID｜假设/变量｜创作者｜平台｜发布时间｜自然/付费｜曝光｜点击｜激活｜去重付费｜退款｜净收入｜制作费｜投放费｜人工｜状态`

比较同产品、尽量相同格式/落地页/窗口的素材，每次主要改变一个变量。曝光未知只能比较收藏绝对数，不能比较收藏率；推荐系统分流不同，所以自然流量对比不是严格因果实验。记录样本局限与未知来源。

UTM与代码按预先约定规则映射付款，明确冲突优先级与跨设备漏记。实际现金CAC以已发生成本除以归因新增付费用户，0付费时不可计算；完整成本还需人工/工具，不把分佣当全部CAC。

## 6. 复盘与下一步

先看主要业务结果和下游质量，再看曝光/收藏。点击高但任务完成低，检查内容承诺与页面是否不一致。预算或时间到上限仍证据不足，记录未定论并选择补数据、改单一变量或停止；不用“找到了爆款”掩盖付款未知。

## 7. 平台适配与规模化

按本项目实际受众、格式、传播规则和可测事件选择平台，不设普遍市场进入顺序。上线前核对当前平台规则；使用真实身份、原创或获授权素材、适当披露。不买评、不做假互动、不绕过平台限制。

先确认团队能完成验收、回复和结算，再增加创作者与发布频率。每周维护已验证格式、失败假设和权利到期记录；第三方工具可选，用手工台账也能运行。
