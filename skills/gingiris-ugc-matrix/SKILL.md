# UGC 创作者运营与素材实验

## 何时使用

用户要招募创作者、写 Brief、安排素材生产/分发、选择激励或复盘素材表现时使用。先确定传播、激活还是实际付费目标。本包独立可用，不需要额外 skill 或付费工具。

## 开场最少输入

产品与真实任务、目标人群/地区、业务目标、自然分发或付费投放、当前渠道数据、现金/工时上限、素材和肖像授权、负责人。缺失信息标待确认；可先交草稿，不编造产品功能或承诺。

## 执行顺序

1. **确定结果**：播放、收藏、激活与付款分别定义，记录窗口和去重规则。收藏120比30多不代表收藏率更高，曝光未知时不算率。
2. **选择创作者**：按目标人群/任务理解、原创能力、演示准确性、沟通与授权筛选。需要探索方向时给目标和约束；执行已有格式时提供获授权样例。人数与预算匹配，不默认80人团队。
3. **制作 Brief**：使用 [完整SOP](references/full-sop.md) 的模板，说明受众、事实、演示、CTA、交付规格、修改和复用权。创作者可以拒绝虚假见证，不要求好评。
4. **验收与发布**：成片验收、上线、投放、复盘和结算分开。先测试链接/事件与披露；对外发布和付费操作按用户授权执行。
5. **激励与归因**：读 [目标与素材实验](references/outcome-and-variants.md)。传播可选有效触达奖励；成交项目可用制作费加可归因成交奖励，不把不可测销售风险全部交给创作者。
6. **比较与决策**：同项目尽量只改一个变量，保留ID、平台、时间窗、自然/付费流量、分母和下游质量。自然推荐不是随机A/B。到达上限仍无证据时报告未定论，不强行选赢家。

## 必交付物

- 一页目标卡：阶段、业务结果、基线、预算/工时、负责人和复盘日。
- 创作者筛选条件与 Brief，含制作、修改、授权和验收条件。
- 素材台账：ID、假设、平台、来源、发布时间、曝光/点击/激活/付款、成本。
- 归因与结算规则：窗口、去重、退款、冲突、未知来源、奖励上限和结算日。
- 继续/修改/停止建议及证据缺口。

## 质量边界

用获授权素材与真实身份，披露品牌关系、赞助和需披露的AI片段；不伪装独立用户、买评或制造假互动。渠道人口特征与转化高低需要本项目证据，不写成普遍排名。跨平台复用和广告使用需明确授权，不默认免费。

模板中的金额、时长与比例仅为需填写的计划字段，没有保证收益的报价或增长基准。工具只需能完成表格记录、授权管理与事件追踪，免费手工台账也可开始。
