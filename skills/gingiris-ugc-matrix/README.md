# Gingiris UGC Creator Operations

Plan creator recruitment, production briefs, rights, business outcomes and measurement. Version 1.1.1. This package does not promise fixed CPM, revenue or viral results.

## Install

```bash
npx skills add Gingiris-1031/gingiris-skills --skill gingiris-ugc-matrix
```

## Start

“Help us plan UGC for [product/task] and [audience]. Our primary goal is [awareness/activation/payment], budget is [cash/time], current evidence is [counts and windows]. Deliver a creator brief, acceptance checklist, rights and incentive terms, and a measurement plan. Mark unknowns.”

## What you receive

A goal card, creator criteria, production brief, acceptance checklist, attribution/settlement rules and a continue/change/stop decision. Natural distribution and paid reuse are tracked separately. No paid tool or other skill is required.
