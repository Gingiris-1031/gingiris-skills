# Choose the contribution and compensation model

Use when recruiting community advocates, tutorial creators or code contributors. These are different jobs even when people call all three “ambassadors”. A volunteer community case does not establish a no-pay rule for creators with contracted deliverables.

| Track | Selection evidence | Work and compensation | Evaluation |
|---|---|---|---|
| Volunteer community ambassador | Uses the product, helps peers, advocates voluntarily | Self-directed participation; recognition, access and optional benefits agreed openly; no disguised mandatory unpaid production | Useful answers, community trust, sustained voluntary participation |
| Tutorial creator | Can demonstrate a real workflow and explain it to the intended user | Agree deliverables and rights; base fee for content plus optional attributable conversion bonus; official channels may amplify | Accepted tutorials, qualified usage and attributable conversions, not follower count alone |
| Code contributor | Relevant PR quality and collaboration history | Engineering review; paid contractor arrangement where scoped work warrants it | Code quality, review and delivery, separate from marketing metrics |

A small creator pilot can begin once the workflow actually works and suitable users can teach it. A scaled community program needs product usefulness, ownership and support capacity. Do not impose a universal user-count threshold or wait for an arbitrary company stage.

## Agreement and review card

`Track | Selection evidence | Deliverables | Owner | Base fee / benefits | Bonus event | Attribution window and source | Duplicate / refund treatment | Disclosure and usage rights | Review date`

Choose whether the bonus rewards a verified signup, activation or paid conversion; state the definition before work starts. Define how duplicates, invalid events, cancellations and refunds affect settlement. Missing attribution is unknown, not zero. Neither a tutorial nor a meeting proposal proves revenue impact. Set fees from scope and budget, not a historical example amount.

For a volunteer, replace production quotas with mutually agreed optional contributions. For a creator, define acceptance and compensation explicitly; calling someone an ambassador does not remove their delivery costs. For a developer, keep engineering ownership of code review.
