# User Interview & Cold-Start Operations

Version 1.1.1. Plan decision-led research, observe real tasks, recover interviews that become sales demos, and hand off verifiable product changes. Interview counts, interest and assisted onboarding do not prove PMF or paid demand.

## Install

```bash
npx skills add Gingiris-1031/gingiris-skills --skill gingiris-user-interview
```

## Start

“我们的产品是[产品]，要决定[问题]，已有证据[记录]，预算/时间[上限]。请交下一轮样本与访谈提纲、任务观察表、产品验收交接和冷启动成本计划。区分真实行为、主持人帮助、兴趣和付款。”

## Outputs

Sampling and interview plan; consent and observation records; evidence vs proposed solution; owner and observable acceptance; follow-up plan; cash and labor budget with continue/change/stop conditions. No paid tool or additional skill is required. External contact, publishing and transactions require user authorization.
